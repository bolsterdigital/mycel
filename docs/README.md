# docs/

| Path                                                                   | What it is                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`adr/`](adr/)                                                         | Architecture decision records, indexed with their status in [`adr/README.md`](adr/README.md). Read these first; they are short and they are the contract agents build against.                                             |
| [`self-hosting.md`](self-hosting.md)                                   | From an empty server to the first login with `compose.yml`: what you need, the steps, which service holds which credentials.                                                                                               |
| [`upgrading.md`](upgrading.md)                                         | What a self-hoster can rely on between releases and how the repository keeps that true.                                                                                                                                    |
| [`architecture/overview.md`](architecture/overview.md)                 | The package map and the rules between packages, with a link to every reference page.                                                                                                                                       |
| [`architecture/testing.md`](architecture/testing.md)                   | Which conformance suite a change must grow, and the ratchets in `npm run lint:infra`.                                                                                                                                      |
| [`architecture/extensibility.md`](architecture/extensibility.md)       | Accepted routes for managed extensions, configurable forms and external ownership, with ADR links and implementation status.                                                                                               |
| [`architecture/frontend-quality.md`](architecture/frontend-quality.md) | The measurable frontend contract: Lighthouse, accessibility and task-level gates.                                                                                                                                          |
| [`architecture/content-layout.md`](architecture/content-layout.md)     | The shared content rails of public pages and previews.                                                                                                                                                                     |
| [`architecture/review.md`](architecture/review.md)                     | How a pull request is reviewed: the six-field record, the eight lenses, the project profile (`review-profile.json`) and `scripts/review-signals.mjs`, which maps a diff through it.                                        |
| `plans/`                                                               | **Symlink to the private planning sibling** `../mycel-planning`. Gitignored here; the sibling is its own private repo. On a fresh checkout: `ln -s ../../mycel-planning docs/plans` from the repo root.                    |
| [`reference/`](reference/)                                             | One page per module or contract (constants included), all listed under "Reference pages" in [`architecture/overview.md`](architecture/overview.md). The proxy is [`../docker/caddy/Caddyfile`](../docker/caddy/Caddyfile). |

Contributor-facing docs (setup, conventions) live in [`../CONTRIBUTING.md`](../CONTRIBUTING.md) and the root [`CLAUDE.md`](../CLAUDE.md), which is also `AGENTS.md`.
