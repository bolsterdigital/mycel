# Extensibility and external ownership

These are accepted design contracts, not implemented capabilities. The current signup, block registry, theme and outbox remain the implementation baseline. Use the linked ADRs to plan new work and the [testing strategy](testing.md) to prove it; do not infer that an extension loader, connector catalogue or form action editor already exists.

| Need                                      | Accepted route                                                                                                                                                                                  | Decision                                                                                                                 |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Ordinary site styling and layout          | Validated theme values, block variants and patterns remain the default; effective values and override provenance must be visible.                                                               | [ADR 013](../adr/013-customisation-ladder.md), [ADR 022](../adr/022-managed-extensions-and-site-integrations.md)         |
| A one-site block or design treatment      | A trusted operator installs and activates a versioned managed package for the selected scope. It need not become a general product feature; arbitrary tenant code uploads remain excluded.      | [ADR 022](../adr/022-managed-extensions-and-site-integrations.md)                                                        |
| A different editorial shape               | Choose a block, then a type profile over `page` or `article`; a new domain entity or lifecycle needs a new ADR. Apply publication and access rules across every representation.                 | [ADR 012](../adr/012-content-types-and-publishing.md), [ADR 022](../adr/022-managed-extensions-and-site-integrations.md) |
| A consent manager, tags or live widget    | Register owner, routes, consent, destinations and kill switch; exclude admin and editorial preview and review sensitive public routes. Use a bounded embed with fallback for third-party media. | [ADR 022](../adr/022-managed-extensions-and-site-integrations.md)                                                        |
| Everyday form routing                     | Typed fields, bounded server-authoritative conditions, multiple per-form notifications and connector actions, with versioned identity and effective template preview.                           | [ADR 023](../adr/023-configurable-forms-and-actions.md)                                                                  |
| A permanent external CRM or mail platform | Name the domain and consent owner; use a self-service connector, signed webhook or inventoried one-off relay, with outbox intents and reconciliation. Native Mycel remains an option.           | [ADR 024](../adr/024-managed-integrations-and-external-ownership.md)                                                     |
| An external subscription system           | Make charging authority exclusive and verify external status before granting access; a PSP adapter alone does not transfer subscription ownership.                                              | [ADR 005](../adr/005-money-ledger.md), [ADR 024](../adr/024-managed-integrations-and-external-ownership.md)              |

The core stays framework-free and tenant-scoped ([ADR 001](../adr/001-framework-free-core.md), [ADR 002](../adr/002-single-postgres-rls-tenancy.md)). Selective activation and browser asset loading do not isolate server code. Trusted packages co-release with the host; untrusted backend work runs through an authenticated external boundary. The same architecture is open to self-hosters, and licensing follows [ADR 006](../adr/006-open-core-licensing.md), not package naming.
