# Demo photos

The four photographs the dev seed (`src/runtime/seed-demo.ts`) uploads into the demo page and article of tenant `probe`. Each is in the public domain under CC0 1.0, so it may be redistributed with this AGPL repository; none shows an identifiable face. Busy textures (jute, brick facades) were rejected: at the platform's AVIF quality they broke the 60 KB budget of a phone-width image. The seed reads these files and never fetches anything.

Each file is the source image auto-oriented, scaled to at most 1920 pixels on its long side (the largest variant width, `VARIANT_WIDTHS`), stripped of metadata and encoded as JPEG (mozjpeg, quality 78) with sharp. The media pipeline derives every rendition from it; no page serves this file directly.
