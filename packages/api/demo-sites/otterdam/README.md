# Otterdam demo photos

The ten photographs the demo site runner (`src/runtime/seed-site.ts`) uploads into the fictional otter charity Otterdam (MY-264). Each is a work of a United States federal agency (U.S. Fish and Wildlife Service or National Park Service) and in the public domain, so it may be redistributed with this AGPL repository. None shows a person. They come in five shapes (landscape 3:2 and 4:3, wide 16:9 and about 2:1, square and portrait), so every image layout has something to show. The runner reads these files and never fetches anything.

Each file is the Commons thumbnail of the original at 1920 or 1280 pixels, auto-oriented, scaled to at most 1600 pixels on its long side (1400 and 1200 for the two that otherwise passed 150 KB), stripped of metadata and encoded as JPEG (mozjpeg) with sharp. `otter-portret.jpg` is a square cut from the right of the original. The media pipeline derives every rendition from these files.

The source SHA-1 is the one Wikimedia Commons reports for the original upload, checked on 2026-11-21. `demo-photos.test.ts` holds the file hashes and dimensions, so a replaced or recompressed file fails until this table and `OTTERDAM_PHOTOS` in `@mycel/core/testing` agree with it.

A photo from a state or local agency, a zoo or a "courtesy of" credit does not belong here, even when Commons tags it as public domain: only a federal employee's own work is.

`otterdam-logo.svg` is the site's logo: an otter's head above two waves, drawn for this repository as plain SVG shapes (no text, no external references), so it passes the logo upload's SVG check. It is not a photograph and has no row in the table.
